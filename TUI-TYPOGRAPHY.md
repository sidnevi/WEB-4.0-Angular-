# Типографика Taiga UI 5

Компоненты используют семейство из `--tui-typography-family-text`. Для карток сохранены точные метрики исходного SVG:

- caption: `13/20`;
- title: `15/20`;
- «Скрыть»: `--tui-typography-ui-2xs` (`11 px`);
- counter: `--tui-typography-ui-2xs` (`11 px`) + tabular digits.

Семейство шрифта и метрики поставляет `@taiga-ui/styles/taiga-ui-fonts.less`, подключённый Angular builder.
