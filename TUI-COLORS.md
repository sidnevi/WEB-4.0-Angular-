# Цвета Taiga UI 5

Тема подключена через официальный `ng add taiga-ui` и принудительно зафиксирована в режиме `light`. Системная тёмная тема не меняет интерфейс. Цвета продолжают использовать настроенные семантические переменные Taiga UI 5:

- поверхности: `--tui-background-base`, `--tui-background-base-alt`, `--tui-background-elevation-*`;
- интерактивные состояния: `--tui-background-neutral-1*`;
- текст: `--tui-text-primary`, `--tui-text-secondary`, `--tui-text-tertiary`;
- границы и тени: `--tui-border-normal`, `--tui-shadow-*`;
- статусы: `--tui-status-positive`, `--tui-status-negative`, `--tui-status-warning`.

Цвета внутри экспортированных иллюстративных SVG не заменяются CSS-токенами, потому что являются частью самих ассетов.
